## Reveal: what was this experiment really about?

A retrieval-augmented system can separate **how information is represented and searched** from **where factual content is stored**.

The frozen encoder supplied a semantic query space. The external documents supplied editable memory. Updating a fact therefore required changing the memory and its index, not changing the encoder's weights. The closed-book baseline behaved differently because its answers were encoded in learned parameters and became stale when the world changed.

Retrieval also creates a new failure mode. The correct fact can exist in memory and still fail to influence the answer because it was not retrieved, ranked highly enough, or used correctly downstream. Modern RAG systems therefore need diagnostics for retrieval and generation separately.
