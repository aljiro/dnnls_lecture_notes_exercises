## Reveal: what was this experiment really about?

The usual train/test picture says learning stops when deployment begins. Here it did not: the base classifier stayed frozen, but a small set of parameters was **updated using the current unlabelled test distribution**.

That is test-time adaptation. The labels were used only to evaluate whether the adaptation helped; the update itself followed a self/unsupervised proxy objective. This makes the choice of proxy objective crucial. Matching source statistics was useful when the target shift really resembled a global coordinate transformation, but class-prior shift could violate that assumption and make the same adaptation misleading.

The important distinction from in-context learning is concrete: in Experiment 1 the weights never changed. Here some parameters **did** change during inference.
