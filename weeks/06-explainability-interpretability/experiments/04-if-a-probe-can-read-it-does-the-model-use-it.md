## Reveal: what was this experiment really about?

A **probe measures decodability**: whether information can be recovered from a representation by the probe you chose. It does not by itself show that the original predictor uses that information.

Here the shared hidden representation retained nuisance because another objective—the reconstruction head—needed it. A linear probe could read it. But direct interventions showed that the classification decision depended far more on the true signal.

This distinction is fundamental:

`information is present` is not the same claim as `information is used for this prediction`.
