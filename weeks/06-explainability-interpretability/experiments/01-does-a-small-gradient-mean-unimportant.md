## Reveal: what was this experiment really about?

A gradient is a **local sensitivity**, not a universal measure of importance.

A saturated sigmoid can have an almost-zero probability gradient even when a feature was decisive in moving the model from its baseline state to its current confident prediction. Integrated Gradients partly addresses this by accumulating sensitivities along a path, but it introduces another modelling choice: the reference point.

The broader lesson is that an attribution is always conditional on **what scalar is explained, at which input, relative to which reference, using which method**.
