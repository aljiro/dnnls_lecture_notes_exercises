## Prompt 3

> Test the explanation maps behaviourally. On at least 100 correctly classified marked digit-8 test images, take the Integrated-Gradients ranking of pixels for the digit-8 logit. For each image create four interventions: (1) erase the 4x4 shortcut patch; (2) erase the top 5% highest-attribution pixels; (3) erase the same number of pixels chosen uniformly at random using fixed seeds and average over several random draws; (4) erase a matched 5% of LOW-attribution pixels. Measure the change in digit-8 logit and the fraction of predictions that flip for each intervention. Reuse the same trained model. Show the aggregate results plus a few before/after examples.

### Questions

1. Which intervention changes the model's output most?
2. Does removing high-attribution pixels have a larger effect than removing random or low-attribution pixels?
3. Does erasing the shortcut patch confirm or contradict what the heatmap suggested?
4. Why is this intervention stronger evidence than visual inspection alone?

## Reveal: what was this experiment really about?

This experiment was about **faithfulness**.

A saliency or attribution map is easy to look at and easy to overinterpret. The stronger question is whether the highlighted features actually matter to the model's behaviour. Perturbing high-attribution pixels and comparing the result with matched random/low-attribution controls turns the picture into a testable claim.

The shortcut also separates two questions:

- *What evidence is present in the image?*
- *What evidence does this particular model depend on for this particular prediction?*

The second question requires intervention, not aesthetics.
