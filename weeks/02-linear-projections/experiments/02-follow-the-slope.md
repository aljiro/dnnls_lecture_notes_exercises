## Reveal: what was this experiment really about?

The objective was to build an intuition for **gradients and gradient descent as a way of changing parameters in response to a loss**.

A gradient is local information about how the loss changes when the parameters change. Gradient descent repeatedly moves the parameters in the opposite direction. The learning rate decides how large each move should be.
