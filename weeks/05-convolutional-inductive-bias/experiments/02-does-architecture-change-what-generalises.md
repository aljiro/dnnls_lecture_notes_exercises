## Reveal: what was this experiment really about?

The experiment compared two learners with different **inductive biases**.

The flattened MLP can, in principle, learn the task, but each input pixel reaches the hidden layer through position-specific weights. Seeing a motif on the left does not automatically teach the model how the same motif should be treated on the right.

The CNN instead reuses local detectors across spatial locations. This makes the intended rule—recognise the same local structure wherever it appears—much easier to discover from restricted training data.

When you widened the MLP's training positions, more data explicitly taught it some of the behaviour that convolution already encouraged architecturally. Inductive bias and data therefore interact: architecture changes which solutions are easy to learn from the examples available.
