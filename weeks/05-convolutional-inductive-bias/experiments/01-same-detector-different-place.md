## Reveal: what was this experiment really about?

You have just encountered the central architectural biases of a convolutional layer.

A convolution looks only at a **local receptive field** at one time and reuses the **same weights** at every spatial location. When the input pattern moves, the corresponding activation in the feature map moves too. This is **translation equivariance**: translating the input produces a corresponding translation in the feature map.

The important idea is not merely the convolution formula. It is the assumption encoded by the architecture: **a useful local pattern may matter wherever it appears**. Because the same detector is reused, the network does not need to relearn it independently at every location.
