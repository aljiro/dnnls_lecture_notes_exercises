## Reveal: what was this experiment really about?

An embedding gives each token a learned or chosen vector, but **token embeddings alone do not solve the sequence problem**.

If we combine token vectors with an order-invariant operation such as averaging, sentences containing the same multiset of tokens become indistinguishable. Some mechanism must preserve or use order. Recurrent networks do this by repeatedly updating a hidden state as tokens arrive; transformers later do it using attention plus positional information.

The important distinction is:

`representing the symbols` is not the same as `representing their order and relationships`.
