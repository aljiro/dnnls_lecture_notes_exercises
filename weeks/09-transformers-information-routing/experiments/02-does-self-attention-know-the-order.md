## Reveal: what was this experiment really about?

Self-attention lets each token compare itself directly with every other token, but **content comparison alone does not tell the model where those tokens occurred**.

Without a positional signal, a self-attention network followed by an order-invariant pooling operation cannot reliably distinguish suitable permutations of the same token multiset. Positional embeddings attach location information to the token representation so attention can learn relationships such as “before” and “after.”

Multi-head attention adds multiple learned interaction spaces, not an automatic notion of order.
