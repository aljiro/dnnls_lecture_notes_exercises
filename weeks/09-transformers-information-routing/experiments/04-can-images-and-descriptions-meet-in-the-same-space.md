## Reveal: what was this experiment really about?

The two pretrained encoders already represented useful visual and linguistic structure, but they spoke **different coordinate languages**.

Contrastive learning trained small projections so matched image/text pairs became relatively similar while mismatched pairs became less similar. The supervision came from the pairing itself: no separate semantic class label was required.

The result is a shared space useful for **cross-modal retrieval**. That is related to multimodal fusion, but it is not yet the same thing as allowing text to select different pieces of visual evidence inside one example.
