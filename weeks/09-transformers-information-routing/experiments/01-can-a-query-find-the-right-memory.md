## Reveal: what was this experiment really about?

Attention is a **content-dependent routing mechanism**.

A query represents what the current computation is looking for. Keys describe how stored items can be matched, and values contain the information returned after the match. Dot products produce compatibility scores; softmax turns those scores into weights; the weighted value sum produces a differentiable retrieval result.

The crucial idea is that changing the query can change which part of the same memory matters.
